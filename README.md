# Banking System

Реализация системы банкомата с консольным интерфейсом, разработанная в рамках лабораторной работы по предмету "Объектно-ориентированное проектирование и программирование на C#".

[Подробное условие](TASK.md)

## Функциональность

### Режим пользователя
- **Вход в систему** по номеру счета и PIN-коду
- **Просмотр баланса**
- **Снятие денежных средств**
- **Пополнение счета**
- **Просмотр истории операций**

### Режим администратора
- **Вход в систему** с системным паролем
- **Создание новых счетов**
- **Изменение системного пароля**

## Архитектура

Проект реализован с использованием **гексагональной архитектуры** с элементами **луковой архитектуры**, что обеспечивает:

- Четкое разделение ответственности между слоями
- Независимость бизнес-логики от инфраструктуры
- Легкость тестирования и поддержки

### Структура проекта
```
BankingSystem/
├── Application/                                # Слой приложения
│ ├── BankingSystem.Application                 # Основная логика приложения
│ ├── BankingSystem.Application.Abstractions    # Интерфейсы репозиториев
│ ├── BankingSystem.Application.Contracts       # Контракты 
│ └── BankingSystem.Application.Models          # Доменные модели
├── Infrastructure/                             # Слой инфраструктуры
│ └── BankingSystem.Infrastructure.DataAccess
│ ├── Migrations/                               # Миграции базы данных
│ ├── Plugins/                                  # Конфигурация маппинга
│ └── Repositories/                             # Реализации репозиториев
└── Presentation/                               # Слой представления
└── BankingSystem.Presentation.Console
└── Scenarios/                                  # Консольные сценарии
```


## Технологии

- **.NET 8.0** - платформа разработки
- **PostgreSQL** - система управления базами данных
- **Npgsql** - драйвер PostgreSQL для .NET
- **Spectre.Console** - библиотека для создания красивых консольных интерфейсов
- **FluentMigrator** - инструмент для управления миграциями БД
- **NSubstitute** - библиотека для создания mock-объектов (в тестах)

## Требования

- .NET 8.0 SDK
- Docker и Docker Compose (для запуска PostgreSQL)

## Запуск приложения

1. **Запуск базы данных:**
   ```bash
   cd docker
   docker-compose up -d
   ```
2. Запуск приложения:
    ```basn
    dotnet run --project BankingSystem
    ```

## База данных

Используется PostgreSQL с следующими основными таблицами:

- `bank_accounts` - информация о банковских счетах

- `transactions` - история операций

- `admin_passwords` - системные пароли администратора

Миграции управляются с помощью FluentMigrator.

## Конфигурация

- Системный пароль администратора параметризуем

- Подключение к БД настраивается через переменные окружения

- Используется зависимостная инъекция для управления компонентами

## Особенности реализации

- Запрет на использование ORM - прямой SQL через Npgsql

- Богатая доменная модель с инкапсуляцией бизнес-правил

- Обработка ошибок и валидация входных данных

- Персистентное хранение данных в реляционной БД

- Модульная архитектура с возможностью легкого расширения
